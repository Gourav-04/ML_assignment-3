# Experimental protocol fixed before evaluation

**Q1a.** Does a first layer benefit from grouping neighbouring pixels? Apply the identical patch MLP to contiguous 4×4 RGB patches and to 4×4 groups formed after one fixed shuffle of RGB pixel locations. The same permutation is used across examples and splits. All coordinates remain available. This control holds weight sharing, parameters, input dimension, minibatch order, optimizer, and activation functions fixed. The ordinary dense MLP supplies a reference. The controlled pair tests the grouping mechanism inside the patch architecture. A dense-versus-patch difference alone could also reflect different connectivity.

**Q1b.** Fix a stratified subset of 4,000 training examples. Replace 25% of labels uniformly with an incorrect class and keep each replacement throughout training. Log clean validation accuracy, unchanged-label accuracy, and both original- and assigned-label accuracy on exactly the same flipped images. Original labels of flipped examples are used only to score the trajectory. Define a descriptive onset in advance: first epoch where clean validation exceeds 20% versus first epoch where assigned-label accuracy exceeds 20%. Show full trajectories because a threshold does not pinpoint a universal onset. Random guessing is 10%.

**Q2.** Match parameter counts within 5% and use identical epochs, batch size, order, Adam learning rate, checkpoint rule, and preprocessing. This matches update and parameter budgets; FLOPs differ. Predict a greater clean-to-pixel loss for the CNN than for a dense MLP: the fixed shuffle disrupts local pixel adjacency, while the dense first layer can absorb a column permutation. The third condition shuffles 4×4 tiles with a fixed map. Relative recovery from pixel shuffle supports the local-neighbourhood explanation. Remaining loss relative to clean is consistent with a role for larger-scale layout or tile-boundary effects. The two shuffles use new training runs. Compare error counts and mean maximum softmax confidence among errors.

**Q3.** Select the smallest validation MSE across bottlenecks 8, 32 and 128 (first maximum/minimum resolves a tie throughout). Fit a fresh denoising model of the winning size on independently regenerated, clipped Gaussian noise (SD 0.2). Across conditions, use identical evaluation corruption and the same frozen clean CNN. Freeze clean encoders and fit a standardized multinomial logistic probe per size on all training features. Fix probe C=1 before testing. Models see no test labels until all choices are frozen.

**Q4.** Freeze the validation-selected clean AE representation. Use the same predetermined stratified 5,000-point training subset for all kernel fits and clustering. Fit feature scaling on this subset. Select the kernel/C combination with best validation accuracy, using the loop order in config.json to break ties. Use RBF gamma=scale and polynomial degree 3, gamma=scale, coef0=0. Select k for k-means using validation silhouette on a seeded sample of 2,000; no labels are used for fitting or choosing k. Obtain one-versus-one decision values for the three most confused unordered test pairs. A low absolute pair score indicates closeness to that pair's boundary within that classifier; the multiclass vote can still pick a third label. Compare class-conditional test errors with the contingency table.

Before official test evaluation, an initial C grid of 0.01 through 100 was abandoned for runtime. The final shared grid is 0.0001, 0.001, 0.01, 0.1 and 1. Results from the abandoned training/validation attempt are excluded.
